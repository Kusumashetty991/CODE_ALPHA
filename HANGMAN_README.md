# Hangman Game – Python

## Project Description
This project is a simple text-based Hangman game developed using Python. The player tries to guess a hidden word one letter at a time within a limited number of incorrect guesses.

## Features
- Contains 5 predefined words.
- Allows the player to guess letters.
- Limits incorrect guesses to 6.
- Displays guessed letters and remaining attempts.
- Simple console-based gameplay.

## Technologies Used
- Python

## Key Concepts Used
- Random module
- While loop
- If-else statements
- Strings
- Lists

## How to Run
1. Install Python.
2. Download the `hangman.py` file.
3. Run the file using Python.
4. Guess letters to complete the hidden word.
