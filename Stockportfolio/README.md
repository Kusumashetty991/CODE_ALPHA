# Stock Portfolio Tracker

## Project Description
The Stock Portfolio Tracker is a simple Python program that calculates the total investment value of stocks based on predefined stock prices and user-entered quantities. It allows users to enter stock names and the number of shares they own, and displays the total value of their investment.

## Features
- Predefined stock prices using a Python dictionary.
- Accepts stock names and quantities from the user.
- Calculates the total investment value.
- Displays the final portfolio value.
- Simple and beginner-friendly console interface.

## Technologies Used
- Python

## Concepts Used
- Dictionaries
- User Input
- Variables
- Basic Arithmetic Operations
- Conditional Statements

## How to Run
1. Download the `stockportfolio.py` file.
2. Open it in Python.
3. Run the program.
4. Enter the stock name and quantity when prompted.
5. View your total investment value.
